# Online Clothing & Fashion Store

A full-stack e-commerce web application developed
as part of the NetLinks Software Engineering
in Practice Bootcamp 2026.

## Project Overview

The platform aims to provide customers with an
online shopping experience where they can explore
fashion products, select clothing sizes and colors,
manage shopping carts, and place orders.

Administrators will have a dedicated dashboard
for managing products, categories, inventory,
customers, and orders.
